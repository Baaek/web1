# 📖 「요르문간드 연대기」 원고

> **캐논 정본은 [`../worldbuilding/`](../worldbuilding/README.md)이다.** 이 디렉터리는 원고만 둔다.
>
> 집필 세션의 규칙은 [`../CLAUDE.md`](../CLAUDE.md) 5절 참조.

## 규칙

- **파일명**: `NNN-제목.md` (예: `001-그날-밤에도-비가-왔다.md`). 화차 번호는 세 자리로 고정
- **집필 중 캐논을 고치지 않는다.** 어긋남을 발견하면 아래 「캐논 이슈」에 적어두고 설정 세션으로 넘긴다
- **정본 우선순위**: 이 디렉터리의 원고 > [17번 진행표](../worldbuilding/17-백정-에피소드-진행표.md) > [05-트래커](../worldbuilding/05-트래커.md). **원고와 진행표가 어긋나면 진행표를 고친다**
- 인물을 쓰기 전에 `../worldbuilding/characters/<이름>/심리엔진.md`의 **「6. ACTION STRATEGY FOR WRITER」**를 읽는다

## 정해진 것 (잠정)

상세와 근거는 [집필회의록](./집필회의록.md), 화기 서술은 [총기자료](./총기자료.md), 사내 장면은 [회사생활자료](./회사생활자료.md).

| 항목 | 값 |
|---|---|
| **시점** | 본편 **3인칭 제한 + 자유간접화법** / 외전 **1인칭** |
| **분량** | 회당 **6,000자**(공백 제외) |
| **총 화수** | **300화** — 뼈대 88 / 외전 27 / 에피소드 185 |
| **전개** | 옴니버스. 1화 완결 에피소드가 다수 |
| **1화 시작점** | 2026년 9월, 진행표 ①번. 밤 교전 콜드 오픈 → 낮의 회사 |
| **표기** | lot은 **「랏」**으로 쓴다 (「로트」 아님) — 조사는 받침 ㅅ 기준: 랏이·랏을·랏은·랏과 |
| **사내 생활** | 삼성전자 DS부문 PI·수율 엔지니어의 실제 생활을 모델로 한다 — 기준은 [회사생활자료](./회사생활자료.md) |
| **호칭** | 동료는 **「○ 프로」**, 직책자는 **「파트장님」**. 백 정은 **CL3**(옛 과장급). **민 파트장만 「백 과장」이라고 부른다** |

2016년 부산항은 **外傳 一**(40화 전후)로 따로 쓴다.

**001~005화는 도입 묶음이다.** 2026년 9월 9일 수요일 밤 하나에서 전부 파생된다. 옴니버스는 **006화부터** 연다 — 근거는 [집필회의록 12-4](./집필회의록.md).

## 캐논 이슈

집필 중 발견한 설정 어긋남을 여기 쌓아두고, **설정 세션에서 처리한다.**

| 발견 | 내용 | 처리 |
|---|---|---|
| 001화 | **정착 검진 대상 범위** — 심도 1 미등급 각성자도 검진 의무인지 [13번](../worldbuilding/13-헌터제도와권역.md)에서 확인되지 않음. 1화에서 하 과장(심도 1 정 계통, 미등급)이 검진받는 것으로 썼다 | ⬜ |
| 001화 | **소형 게이트 개체** — 수각류형·역관절 개체를 이름 없이 썼다. 백 정은 은어를 쓰지 않으므로 본문에서는 "개체"로만 부른다. [12번 8-3절 도감](../worldbuilding/12-몬스터체계.md) 등재 여부는 설정 세션 판단 | ⬜ |
| 001화 | **월별 게이트 발생 통계** — "전월 대비 발생 건수 9% 감소" 같은 협회 집계가 존재하는지 미확인. 회사 장면이 이 수치에 기대고 있다 | ⬜ |
| 002화 | **무등록 채집물의 유통 경로** — 협회에 등록하지 않고 뜬 소재를 누구에게 넘기는지 캐논에 없다. 2화에서는 인물을 만들지 않고 "내일 넘긴다"로만 처리했다. 소재상·중개상이 필요하면 설정 세션에서 세울 것 | ⬜ |
| 002화 | **잔존 개체 사체 처리 절차** — 닫힌 게이트 주변 사체를 협회가 "자연사"로 처리한다고 썼다. [13번](../worldbuilding/13-헌터제도와권역.md)에 해당 절차가 없다 | ⬜ |
| 002화 | **자상 환자 의료기관 신고 의무** — 백 정이 병원을 피하는 근거로 썼다. 현행법 유추이고 캐논 근거는 없다 | ⬜ |
| 002화 | **탄피·탄도 식별 수사 체계** — 각성자 시대의 총기 규제와 과학수사 수준이 미확인. 2화는 "탄피를 남기면 총이 특정된다"를 전제로 움직인다 | ⬜ |
| 003화 | **채집인 협회 등록번호 체계** — 10자리(지역3·발급4·검증3) 구조를 3화의 핵심 단서로 썼다. 캐논에 근거 없음. 설정 세션에서 세우거나 3화를 고쳐야 한다 | ⬜ |
| 003화 | **권역 번호 부여** — "경기 북부 3권역"이라고 썼다. [13번](../worldbuilding/13-헌터제도와권역.md)에 권역 개념은 있으나 번호 체계는 없다 | ⬜ |
| 003화 | **철조망을 뜯은 자** — 3화 마지막은 각성자 개입을 암시하고 ②번 비트(2026-12 「낮과 밤이 같은 물건이다」)로 이어지는 씨앗이다. **누구인지 설정 세션에서 정해야 한다.** 조직인지 개인인지에 따라 ②번 구성이 달라진다 | ⬜ |
