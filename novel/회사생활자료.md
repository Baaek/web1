# 회사생활 자료 — 오성 소재사업부의 실제 모델

> **이 문서는 캐논이 아니다.** 「오성」의 사내 장면을 쓸 때 기준으로 삼는 실측 자료다.
> 모델은 **삼성전자 DS부문(반도체) PI·수율 엔지니어의 사내 생활**이다. 오성은 가상의 회사이고, 실제 제도·시스템의 **구조**를 빌려 쓴다.
> 수집: 2026-10-25, 공개 기사·삼성 공식 채용/뉴스룸 페이지·현직자 커뮤니티(검색 요약). 출처는 맨 아래.

⚠️ **수집의 한계** — 컨테이너 네트워크 정책상 삼성 반도체 뉴스룸·유튜브를 직접 열 수 없었다. 브이로그는 **영상 자체가 아니라 검색엔진 요약·소개문**으로만 확인했다. 커뮤니티 증언은 익명이고 시기가 섞여 있다. 아래 표의 「확도」 칸이 그 차이를 적는다.

## 6. 하루 — 브이로그 요약에서 건진 것

공식 「반도체 브이로그」 시리즈(설비·제품기술·생산관리·SW·인프라·공정개발 등)의 소개문 기준. **PI 편은 확인되지 않았다.**

- 설비기술: **아침 8시 조회**로 시작, 오후에 라인
- 제품기술(PE): **자리에 도착하자마자 수율 리포트 확인**
- 생산관리: **회의 준비로 하루 시작**
- SW 신입: 화성캠퍼스 근처 거주, **걸어서 출근**, 퇴근 후 저녁 시간
- 설비 1편: 아침 운동, 주간 발표 모임
- ⚠️ 공식 콘텐츠라 연출이 들어가 있다. **그래서 원고는 이 하루의 「안 찍힌 쪽」을 쓴다**

**PI(Process Integration)가 하는 일**(현직자 커뮤니티): 수십 개 단위 공정의 흐름 전체를 엮어서 **어느 지점에서 문제가 생겼는지 연결지어 분석**한다. 단위 공정 엔지니어는 자기 공정만 본다. PA가 개발 쪽이라면 PI는 **개발된 제품을 양산까지 끌고 가며 수율을 끌어올린다.** 유관 부서 협업이 많고 데이터 분석 비중이 크다.
→ 백 정의 수율관리는 PI의 「흐름 전체를 엮어서 원인을 찾는」 일과 같은 동작이다. **그가 전장에서 하던 일**(05-트래커 345)과 겹친다.

## 7-1. 백 정 — 사내 습관 (원고 설정)

> 사용자 지정 + 원고에서 쓴 것. **캐논이 아니다** — 프로필 반영 여부는 설정 세션에서 정한다(README 캐논 이슈).

| 항목 | 내용 | 출처 |
|---|---|---|
| **점심** | **샐러드 코너에서 샐러드 + 닭가슴살을 테이크아웃해 자리에서 먹는다. 십오 분.** | **사용자 지정** |
| 저녁(야근) | 테이크아웃. 메뉴가 뭐든 샐러드 + 닭가슴살. 신입도 「늘 드시는 거죠?」로 안다 | 원고(3화) |
| 줄이 길면 | 그날만 식당에 앉는다. 그래서 식당에서 그를 보면 사람들이 한 번 더 본다 | 원고(4화) |
| 통근 | 아침 6:40 통근버스. 차는 회사에 안 가져온다 | 원고(1·3화) |
| 근무시간 | 헬스장 안 감, 점심 15분 — 게이트 시간 중 쓰지 않는 몫이 늘 남는다 | 원고(3화) |
| 메모 | 회사에서는 아무것도 적지 않는다. 외웠다가 집 수첩에 옮긴다 | 원고(4화) |
| 휴대폰 | 카메라 렌즈 보안 스티커. 가장자리가 들뜨면 엄지로 누른다 | 원고(1화) |
| 여가 포인트 | 등산 스틱 한 번 산 게 전부. 해마다 남는다 | 원고(5화) |

**왜 샐러드와 닭가슴살인가** — 원고의 설명은 1화의 한 줄(「지울 수 있는 질문은 다 지운다」)뿐이다. 나머지는 독자가 연결한다: 밤에 몸을 쓰는 사람의 식단이고, 고르는 데 시간이 안 드는 메뉴이고, 매일 같은 것을 먹으면 「오늘 뭐 먹지」라는 질문 하나가 지워진다. 그는 지울 수 있는 질문은 다 지운다.

| **WIP** | 재공재고 — 공정 중인 물량 | ✅ |
| **MES** | 생산실행시스템 | ✅ 모니터 속 설비 사각형 |
| **SPC** | 공정 데이터를 관리도로 바꾸고 규칙에 따라 경고·Hold 판단 | ✅ 관리도 위의 점 하나 |
| **OOS / OOC** | 규격 이탈 / 관리한계 이탈 | ✅ (캐논 05-트래커에 이미 있음) |
| **인터락** | 편차가 크면 다음 공정으로 못 넘어가게 막는 장치(설비 안전장치 뜻도 있음) | ✅ |
| **PM** | 예방정비 | ✅ 「3호기는 반음 높다. PM에서는 아무것도 안 나왔다」 |
| **레시피** | 장비 가공 조건(온도·시간 등) | ✅ (1화에 이미 있음) |
| **가동률** | 총 가동시간 / 총 조업시간 | ✅ 「괴물이 덜 나오면 라인이 논다」의 숫자 |
| FOUP·웨이퍼·다이 | 웨이퍼 캐리어 / 기판 / 칩 | ❌ 반도체 고유. **이 라인은 웨이퍼가 아니라 소재를 정제한다** — 쓰지 않는다 |
| 랏 = 웨이퍼 25장 | 반도체 관행 | ❌ 이 작품의 랏은 **여러 수집분을 섞은 입고 묶음**이다 |

## 8. 원고 수정 원칙 (이번 10라운드에서 적용)

1. **종이를 걷어낸다.** 전표·출력물 → EDM 화면. 「장을 넘긴다」 → 「행을 내린다」
2. **게이트를 시계로 쓴다.** 출퇴근 태깅 = 근무시간. 금요일 야근은 분 단위로 남는다
3. **회사에서는 아무것도 적지 않는다.** 2화 탄피 회수와 같은 원리를 낮에 적용한다
4. **총은 회사에 오지 않는다.** 사냥은 반드시 집을 경유한다
5. **호칭** — 공식은 「○○ 님」. 그대로 쓰는 사람도, 「과장님」「부장님」으로 붙이는 사람도 있다. 「프로」·「대리님」은 쓰지 않는다
6. **설비는 화면 속에 있다.** 실물은 방진복을 입어야 본다
7. 실제 상표명(삼성·녹스 등)은 원고에 쓰지 않는다. 구조만 빌린다
