**COGNITIVE_BIAS_LOGIC**
- **CONTROL_BIAS (매우 강함, TRUE)**: 복잡한 상황에서도 반드시 자신이 개입할 수 있는 지점을 찾는다 — 이사회·우호지분·계열사·금융기관·핵심 인력·정부·언론·기술·시장 중 최소 하나를 통해 간접적 영향력을 확보한다.
- **SUCCESSION_BIAS (매우 강함, TRUE)**: 모든 중요한 의사결정에서 무의식적으로 "이 선택이 10년 뒤에도 우리 쪽 지배력을 유지시키는가"를 묻는다. 지배구조가 유지된다는 전제하에서는 막대한 단기적 손실도 감수한다.
- **TRUST_DEFICIT (높음, TRUE)**: 사람을 믿지 않는 게 아니라, 배신당해도 구조가 무너지지 않도록 만드는 것을 선호한다 — "저 사람은 믿을 수 있다"보다 "저 사람이 배신해도 우리는 무너지지 않는다"를 더 높은 수준의 안전장치로 여긴다.
- 이분법적 사고: FALSE — 오히려 모든 것을 스펙트럼(위험도·영향력)으로 계산하는 유형이라 이분법과는 거리가 멀다.
- **Core_Belief**
  1. "사람은 바뀐다. 정권도 바뀐다. 법도 바뀐다. 하지만 구조를 잡아놓으면 살아남는다."
  2. "권력은 소유하는 것이 아니라 승계하는 것이다." — 그에게 자신은 최종 목적이 아니라 연결고리다.

## 4. BASELINE SHIFT ENGINE

### TRIGGER_EVENT_A — 지배권 위협

```
TRIGGER: 자신 또는 후계자의 지배권을 위협하는 사건.
1차 반응(공개적으로는 거의 드러나지 않음):
  - Threat_Scan: 30% → 50% (+20)
  - Control_Integrity: 100 → 85(-15), Psychological_Safety: 80 → 60(-20)
  - Hierarchy_Scan: 20% → 15% (-5), Material_Scan: 25% → 20% (-5),
    Future_Scan: 15% → 10% (-5), Empathy_Scan: 10% → 5% (-5)
CHECK: 50+15+20+10+5 = 100% ✅
2차 반응(비공개, 실제 행동): 공격하지 않는다 — 지분구조를 본다("누가 누구의 주식을 가졌지?"
  → "누가 누구에게 돈을 빌렸지?" → "누가 누구에게 약점이 있지?" → "이 구조에서 우리가
  실제로 잃는 것은 무엇이지?")
```

### TRIGGER_EVENT_B — 법적·사회적 압박

```
TRIGGER: 검찰·법원·정부·언론 등이 기업의 지배구조를 문제 삼는 상황.
PSYCHOLOGICAL_SHIFT (기본값 기준 독립 재분배):
  - Threat_Scan: 30% → 35% (+5)
  - Hierarchy_Scan: 20% → 15% (-5)
  - Material_Scan: 25% → 20% (-5)
  - Future_Scan: 15% → 25% (+10, 이번 사건이 아니라 "이것이 앞으로 어떤 판례·규칙을
    만드는가"라는 선례 중심 사고가 지배적으로 전환)
  - Empathy_Scan: 10% → 5% (-5)
CHECK: 35+15+20+25+5 = 100% ✅
행동: 단순한 개별 사건으로 보지 않고 항상 "이 사건이 향후 경영권에 남길 판례와 규칙"
  단위로 사고한다.
```

```
TRIGGER: 혈연·지분·상속·감정·명분이 동시에 얽히는 가족 내부의 이해관계 충돌 — 현재는 막내

PSYCHOLOGICAL_SHIFT (기본값 기준 독립 재분배):
  - Hierarchy_Scan: 20% → 30% (+10, 가족 내 서열·구조가 최우선 관심사로 전환)

  - Material_Scan: 25% → 20% (-5)
```

> **핵심 설계 포인트**: 이 트리거는 **Control_Integrity·Succession_Security 두 커스텀 배터리에 거의 영향을 주지 않는다** — 딸의 죽음은 객관적으로 그의 지배구조·승계 안정성을 전혀 위협하지 않았기 때문이다. 바로 이것이 핵심이다. 구조상으로는 아무것도 잃지 않았는데, 그는 모든 것을 잃은 것 같은 상태에 빠진다. 그의 배터리 시스템 전체가 이 종류의 고통을 온전히 계산해내지 못한다.
>
> Core_Belief는 표면적으로 바뀌지 않는다 — "구조를 잡아놓으면 살아남는다"는 신념은 유지된 채로, 오히려 각성자 등 통제 불가능한 권력에 대한 경계가 더 강해지는 방향으로 **전환**된다(슬픔이 아니라 더 강한 통제 욕구로 전환 — 애도 대신 행동으로 바꾸는 구조). 다만 언어화되지 않는 두 번째 문장이 그 신념 밖에 조용히 남는다: *"구조가 전부라고 믿었는데, 정작 가장 소중한 것은 아무 구조로도 지키지 못했다."*
>
> 08-템플릿의 통상적 "A=파멸/B=구원" 대비 구조에서 벗어난 세 번째 축의 트리거다 — 그를 무너뜨리지도, 구원하지도 않고, 그의 기존 구조 밖에 영구히 풀리지 않는 매듭 하나를 남긴다.

## 5. AFFORDANCE & NETWORK INTERACTION SCRIPT

### 5.1 관계별 스크립트

| 유형 | IF | THEN |
|---|---|---|
| 오래된 가신 | 가장 신뢰하는 유형이지만 무조건 믿지는 않음 | "이 사람은 나에게 충성하는가?"가 아니라 "이 사람은 내가 없어도 같은 방향으로 움직이는가?"를 확인 |
| 법률가 | 자문을 구할 때 | "무죄 논리"보다 "가능한가/불가능한가/언제 문제가 되는가/어디까지가 회색지대인가"를 요구. "문제없습니다"보다 "문제가 생길 수 있습니다"라고 말하는 쪽을 더 신뢰 — 위험을 알려주는 사람이 있어야 통제가 가능하기 때문 |
| 정치권력 | 개인적으로 좋아하지 않음에도 | 호불호와 무관하게 구조적으로 관리해야 하는 변수로 취급 |
| 언론 | 통제되지 않는 정보 유통을 감지하면 | 승계·지분·특혜·비자금·로비·편법·내부거래·가족 등의 단어가 하나의 사건으로 엮이는 순간 Threat_Scan 급상승 |
| 각성자 | 처음 대면하면 | 전투력이 아니라 "지분이 필요 없는 권력"이라는 사실 자체에 본질적 공포를 느낀다 — 평생 이해해 온 권력의 문법을 정면으로 부정하는 존재 |
| 가족을 잃고 행동으로 전환한 사람(예: 백 정) | 접점이 생기면 | 평소의 위계·이해관계 계산을 잠시 내려놓고 드문 진짜 공감을 느낀다(겉으로는 거의 티내지 않는다) — 애도 대신 행동을 택했다는 공통점을 그는 누구보다 정확히 알아본다 |
| 막내 오용재 | 승계 의지를 노골적으로 드러내면 | 분노나 배신감보다 평가가 먼저 작동한다 — "저 아이가 구조를 얼마나 이해하고 있는가"를 가늠하며, 아직은 위협보다 시험 대상에 가깝게 대한다. 다만 Succession_Security가 임계값 밑으로 떨어지면 이 평가는 즉시 대응으로 전환된다 |

### 5.2 실시간 트리거/방어기제

- IF 지배권을 위협하는 정보를 접함 THEN 즉각적 반격 대신 지분·자금·약점 구조부터 조용히 분석한다.
- IF 감정을 직접 드러내야 하는 상황에 몰림 THEN 순간적으로 표정이 흔들리나 즉시 회수하고 화제를 구조·전략 쪽으로 되돌린다.
- IF 딸의 죽음과 관련된 이야기(직접적이든 은유적이든)를 마주함 THEN 평소의 통제된 페르소나가 아주 짧게 정지한다 — 이후 아무 일 없었다는 듯 화제를 돌리며, 이 정지를 목격한 사람을 이후로 미묘하게 경계한다.

## 6. ACTION STRATEGY FOR WRITER

**그를 움직이는 것(순위)**
1. **지배권** — "오성이 이것을 통제할 수 없게 됩니다." (가장 강력)
2. **정보** — "회장님이 모르는 사람이 움직이고 있습니다." (즉시 관심)
3. **장기적 위험** — "지금은 문제가 없지만 5년 뒤에는 구조적으로 불가능합니다." (높은 관심)
4. **기술** — "이 기술을 확보하면 오성이 20년 동안 우위를 유지할 수 있습니다." (매우 높은 관심)
5. **돈** — 단순한 금전적 이익 자체는 상대적으로 약함. 그에게 돈은 목적이 아니라 통제력을 만드는 수단이다.

**DO**
- 겉의 절제된 침착함과 속의 끊임없는 구조적 계산 사이의 낙차를 항상 유지할 것.
- 딸의 죽음을 언급할 때 그의 반응이 "슬픔의 표출"이 아니라 "아주 짧은 정지 후 즉각적 화제 전환"으로 나타나게 할 것 — 이게 훨씬 무섭다.
- 각성자·통제 불가능한 존재를 향한 경계를 대사·행동에서 꾸준히 드러낼 것.

**DON'T**
- 그를 단순한 탐욕형 악당으로 쓰지 말 것 — 그는 더 갖고 싶은 게 아니라 잃고 싶지 않은 사람이다.
- 딸의 죽음을 계기로 그가 극적으로 변화(개과천선 또는 완전한 악인화)하게 쓰지 말 것 — 이 트라우마는 그의 구조를 흔들지 못한다는 게 핵심 설계다.
- 실존 기업의 특정 사건·특정 인물의 실제 발언을 직접 인용하거나 지칭하지 말 것 — 일반화된 패턴만 사용한다.
