# 문태석 — 인물 심리 엔진

> [08-인물심리엔진-템플릿.md](../../08-인물심리엔진-템플릿.md) 구조로 정리. 문태석은 공학 박사 출신의 포병·공병 계열 군인으로, 중화기·폭발물 운용에서 대체 불가능한 실력을 인정받아 2021년 특무관 3번으로 지정된 인물이다. 핵심 성격은 열혈·낙천·책임감이며, 공학적 분석과 인간적인 충동이 동시에 작동하는 구조를 가진다.

## 1. NARRATIVE & EXPLICIT PERSONALITY

- **AGENT_ID**: 문태석 / 대한민국 / 30대 후반~40대 초반
- **기본 인적 사항**: 남성, 대한민국 육군 상사. 포병·공병 계열. 공학 박사 학위 보유. 2021년 상사 정규 진급과 동시에 특무관 6인 중 한 명(3번)으로 지정.
- **특무관 지정 특기**: 중화기·폭발물. 박격포·무반동포·대전차화기·폭약 설치 및 처리에 특화. 대형·장갑형 개체 및 구조물급 위협 대응.
- **인생의 핵심 트라우마**: 2016년 게이트 대발생 초기 대응 과정에서 자신의 공학적 지식과 기존 군사기술만으로는 예측할 수 없는 괴물들과 마주한다. 현장에서 충분한 장비와 화력이 있었다면 살릴 수 있었을 사람들이 죽는 상황을 경험하면서, "방법을 몰랐다는 이유로 죽음을 받아들여서는 안 된다"는 신념이 굳어진다.
- **사회적 페르소나**: 호탕하고 시끄러운 "열혈 박사". 후배들에게 농담을 던지고, 장비를 보면 직접 만져보며, 어려운 상황에서도 "방법이 있겠지"라고 웃어넘기는 사람으로 보인다. 그러나 실제로는 주변 상황과 사람의 위험을 매우 세밀하게 관찰하고 있으며, 자신의 판단으로 누군가 죽는 상황을 극도로 두려워한다.
- **에너지 효율성**: 외향형·활동형. 아침부터 움직이는 것을 선호하며, 장시간 연구나 회의보다 현장·실험·장비 작업에서 에너지가 크게 상승한다. 특히 해결하기 어려운 문제가 주어졌을 때 집중력과 활력이 오히려 증가한다.

**EXPLICIT_TYPOLOGY**
- **MBTI**: ENTP — 새로운 문제를 발견하면 기존 방법에 얽매이지 않고 다른 해결책을 만들어내며, 사람들과 부딪히면서 아이디어를 발전시키는 문제 해결형.
- **에니어그램**: 7번(열정가) — 절망적인 상황에서도 가능성을 찾아내고, 자신과 주변 사람들을 움직이게 만들려는 욕구가 강하다. 다만 7번 특유의 회피성보다 8번(도전자)의 책임감과 행동성이 강하게 섞여 있다.
- **Big 5**: 외향성(E) 85 / 신경증(N) 30 / 성실성(C) 80 / 우호성(A) 75 / 개방성(O) 90

## 2. INTERNAL COGNITIVE PARAMETERS

**ATTENTION_WEIGHT (합 100%)**
- `Hierarchy_Scan` (권력·서열·무시 감지): 10%
- `Threat_Scan` (위험·통제상실 감지): 30%
- `Material_Scan` (장비·자원·물리적 조건 감지): 35%
- `Empathy_Scan` (동료·부하의 감정과 안전 감지): 25%
- 합계: 100% ✅

문태석은 서열 자체에는 거의 관심이 없다. 대신 "지금 무엇이 부족한가"를 가장 먼저 본다 — 탄약이 부족하면 탄약을 계산하고, 화력이 부족하면 다른 무기를 찾고, 무기가 부족하면 지형을 보고, 시간이 부족하면 자신이 위험을 감수한다. 동시에 주변 사람이 얼마나 위험한 상태인지 계속 확인한다.

**COGNITIVE_BIAS_LOGIC**
- 과잉책임화: TRUE — 자신이 해결할 수 있는 문제라고 판단한 뒤 사상자가 발생하면 책임을 자기 쪽으로 끌어온다.
- 행동편향: TRUE — 분석이 충분히 끝난 뒤에는 논의보다 행동을 선호한다. 특히 사람이 위험한 상황에서는 더욱 강해진다.
- 낙관적 편향: TRUE — "아직 방법이 없다"를 "방법이 존재하지 않는다"와 동일하게 받아들이지 않는다.
- 자기희생적 합리화: TRUE — 다른 사람의 생존 가능성을 높일 수 있다면 자신의 생존 가능성을 낮추는 선택을 합리적인 판단으로 받아들인다.
- 이분법적 사고: FALSE — 적과 상황을 단순히 선악·강약으로 나누지 않는다. 문제 해결에 도움이 된다면 기존 교리도 버릴 수 있다.
- **Core_Belief**: "방법이 있는데 포기해서 사람이 죽었다면, 그건 사고가 아니라 내 실패다."

## 4. BASELINE SHIFT ENGINE

```markdown
- [TRIGGER_EVENT_A: 파멸적 트라우마 / 통제력 상실]
  - 조건: 자신의 판단으로 부하 또는 민간인이 사망하고, 사후 분석 결과 "다른 방법이 존재했을 가능성"을 확인하는 사건
  - 성격 및 수치 전이:
    - MBTI 변형: ENTP → ESTP 성향 강화. 장기적 가능성 탐색보다 즉각적인 행동을 우선하는 경향 증가
    - Big5 변동폭: N 30→45(+15), A 75→60(-15), C 80→90(+10)
    - ATTENTION_WEIGHT 재분배 (합 100% 유지): Material_Scan 35%→30%(-5), Threat_Scan 30%→40%(+10), Empathy_Scan 25%→20%(-5), Hierarchy_Scan 10%→10%(±0)
    - Core_Belief 변경: "방법이 있는데 포기해서 사람이 죽었다면, 그건 사고가 아니라 내 실패다." → "내가 직접 통제하지 않으면 결국 누군가 죽는다."
  - 결과: 다른 사람에게 위험한 역할을 맡기는 것 자체를 불안하게 여기며 자신이 직접 해결하려 한다.

- [TRIGGER_EVENT_B: 구원 / 안전기지(Anchor) 확보]
  - 조건: 자신이 모든 것을 해결하려 하지 않아도 동료가 자신의 판단을 이어받아 사람을 살리는 경험을 하고, 그 사실을 받아들이는 순간
  - 성격 및 수치 전이:
    - MBTI 변형: ENTP 핵심 유지. 타인의 능력을 자신의 해결책에 적극적으로 포함하는 방향으로 변화
    - Big5 변동폭: A 75→85(+10), N 30→25(-5)
    - ATTENTION_WEIGHT 재분배 (합 100% 유지): Threat_Scan 30%→25%(-5), Material_Scan 35%→30%(-5), Empathy_Scan 25%→35%(+10), Hierarchy_Scan 10%→10%(±0)
    - COGNITIVE_BIAS_LOGIC 플래그 변경: 자기희생적 합리화 TRUE → 빈도 완화
    - Persona_Durability 소모율 변화: "내가 해결해야 한다" 실패 상황에서의 소모율 30% 감소
    - Core_Belief 변경: "내가 전부 해결하는 게 아니라, 내가 방법을 만들고 사람들이 그 방법으로 살아남게 해야 한다."
```

**설계 의도**: 문태석의 서사는 "열혈남이 냉정해지는 이야기"가 아니다. 그는 마지막까지 열혈이다 — 변화하는 것은 열혈함의 방향이다. 초기에는 자신이 앞장서서 해결하고(영웅), 후기에는 자신이 만든 방법을 다른 사람이 실행할 수 있도록 만든다(지휘자 → 기술자이자 교육자).

## 5. AFFORDANCE & NETWORK INTERACTION SCRIPT

### 5.1 주변 인물(Network) 대응 규칙

- **부하 병사**: `IF` 부하가 위험지역에 투입될 때 `THEN` 보호자형 자아 활성화 — 자신의 위험보다 부하의 생존 가능성을 먼저 계산하고, 단순히 "하지 마라"가 아니라 왜 위험한지 설명하며 대체 방법을 찾는다. 부하가 스스로 위험을 감수하려 하면 화를 낸다. *(백그라운드: 항상 부하의 생존 가능성을 계산)*
- **공병·포병 동료**: `IF` 기술적 문제를 논의할 때 `THEN` 연구자형 자아 활성화 — 계급보다 전문성을 우선하며, 후배의 더 나은 아이디어를 즉시 인정한다.
- **상급자**: `IF` 상급자가 현장 경험 없이 비현실적인 명령을 내릴 때 `THEN` 평소의 호쾌한 페르소나는 유지되지만 내부적으로 강한 반발 — "안 됩니다" 대신 "그렇게 하면 안 죽고 이쪽으로 하면 살릴 수 있습니다"로 설득. 부하의 생존을 비용으로 취급하면 강하게 충돌.
- **각성자**: `IF` 자신보다 압도적으로 강한 각성자를 만날 때 `THEN` 연구자형 자아 활성화 — 질투보다 호기심이 먼저, 능력의 발동 조건과 한계를 관찰하며 신격화하지 않는다.
- **백 정**: `IF` 백 정과 함께 작전을 수행할 때 `THEN` 동료이자 기술적 경쟁자 자아 활성화 — 개인화기 운용을 높게 평가하고 부족한 화력을 보완하는 협업을 선호. 백 정이 위험한 행동을 하면 즉시 제지하되, 먼저 해결책을 찾아내면 크게 웃으며 인정. *(백그라운드: "저 인간이 어디까지 총으로 해결할 수 있는가" 상시 관찰)*
- **차도현**: `IF` 차도현이 신체능력으로 위험한 상황을 해결할 때 `THEN` 감탄과 답답함이 동시 발생 — 능력은 인정하되 "몸으로 해결해도 되는 문제"와 "안 되는 문제"를 구분하려 하며 무리하면 잔소리. 상대가 자신의 방식대로 움직이지 않아도 크게 신경 쓰지 않는다.

### 5.2 실시간 트리거 및 방어기제 발동 규칙

- **[RULE: "방법이 없다"는 판단]** `IF` 작전 책임자가 "현재 방법으로는 해결할 수 없다"고 선언 `THEN` Dopamine_Battery·Persona_Durability 동시 소모 — `IF` (배터리 > 30) → 장비·지형 재분석, 기존 교리 폐기, "잠깐만. 아직 안 해본 게 있잖아." / `ELSE` (배터리 ≤ 30) → 스스로 위험지역 진입, 안전절차 무시, "내가 들어가면 돼."
- **[RULE: 부하 사망]** `IF` 자신의 판단으로 부하가 사망 `THEN` Psychological_Safety 급락 — `IF` (배터리 > 30) → 현장을 냉정히 정리, 원인 분석, 재발 방지책 수립 / `ELSE` (배터리 ≤ 30) → 판단을 반복 검토, 부하를 위험지역에서 배제, 결국 위험을 전부 떠안으려 함.
- **[RULE: 기술적 실패]** `IF` 계산 결과와 실제 현상이 다르게 나타남 `THEN` Dopamine_Battery 소모 — `IF` (배터리 > 30) → 강한 흥미, "재밌네. 그럼 이건 내가 틀린 거네." 새 가설 수립 / `ELSE` (배터리 ≤ 30) → 자기 불신, 혼자 데이터를 반복 검토, 수면 부족 감수.
- **[RULE: 무의미한 희생 명령]** `IF` 상급자가 "몇 명 정도 희생은 감수하라"고 판단 `THEN` Hierarchy_Scan은 거의 작동하지 않고 Empathy_Scan·Threat_Scan 급상승 — `IF` (배터리 > 30) → 대체 작전 즉시 제시, 데이터로 설득 / `ELSE` (배터리 ≤ 30) → 명령에 강하게 반발, 필요시 상급자와 정면 충돌.

## 6. ACTION STRATEGY FOR WRITER

- **Do**: 구체적인 문제 제시("이 몬스터를 어떻게 죽일 수 있습니까?")에 강하게 반응하며 복잡할수록 집중력이 오른다. 장갑 두께·이동속도·구조물 형태 등 기술적 데이터를 많이 줄수록 설득력이 높아진다. "이 방법이면 30명을 살릴 수 있다"는 프레이밍이 가장 강력한 동기 부여. 전문성을 인정하되 "박사님, 그런데 이건 어떻습니까?"처럼 의견을 제시하는 접근을 좋아한다. 후배의 성장 가능성을 보여 주면 자신이 해결하는 것보다 더 자랑스러워한다.
- **Don't**: "원래 방법이 없는 문제입니다"는 사실상 도전 선언으로 받아들여진다. "사람 몇 명 정도는 희생할 수밖에 없다"는 강한 반발을 유발한다. 학위·지식을 권위로 내세우면 오히려 거부감. 각성자를 신격화("인간이 아니니까 방법이 없다")하면 받아들이지 않는다. 그의 자기희생을 영웅적으로 칭찬하면 표면적으로는 웃어넘기지만 내부적으로 자기희생 패턴이 강화된다.

## 부록 — 사용자 제공 원본 서사 (성격·가치관·최종 심리 구조·대사)

### 성격 상세

**평소**: 낙천적 / 말이 많음 / 농담을 좋아함 / 후배를 잘 챙김 / 연구 이야기가 나오면 말이 길어짐 / 장비를 보면 구조부터 분석함 / 새로운 무기나 장비를 보면 직접 만져보려 함

**전투 상황**: 판단이 매우 빠름 / 명령을 기다리기보다 상황을 먼저 해결함 / 위험을 과소평가하는 경향 / 자신이 위험한 역할을 맡는 것을 당연하게 생각함 / 동료가 위험하면 계산보다 먼저 움직임 / 절망적인 상황일수록 오히려 정신력이 강해짐

### 행동 알고리즘 (위기 상황)

1. **문제 정의** — "저 새끼가 왜 안 죽지?"
2. **물리적 원인 분석** — 장갑·외골격·재생·체질량·이동속도·구조적 약점·주변 지형
3. **기존 장비 검토** — 현재 화기로 해결 가능한지 판단
4. **방법 변경** — 화력 → 탄종 → 사격각 → 지형 → 폭약 → 구조물 활용 순
5. **인명 피해 계산** — "이 방법이면 세 명 죽는다" → 다른 방법을 찾는다
6. **마지막 수단** — 다른 방법이 없으면 본인이 들어간다: "좋아. 그럼 내가 한다."

### 가치관 충돌 — 인간의 기술 vs 초월적 힘

각성자 등장 이전엔 아무리 강한 인간도 포병 화력과 장비 앞에서 전략적 의미가 제한적이었다. 하지만 각성자는 혼자서 전차보다 강할 수도 있다. 문태석은 처음엔 이를 인정하기 힘들어하지만 질투하지 않고 오히려 연구한다 — "저걸 기술로 설명할 수 있으면 좋겠는데." 각성자를 신으로 취급하는 순간 인간이 포기한다고 생각하기 때문에, 두려워하면서도 동시에 흥미롭게 바라본다.

### 최종 심리 구조 (욕망 → 성장 흐름)

욕망(사람을 살리고 싶다) → 신념(사람을 살릴 방법은 반드시 존재한다) → 행동(그 방법을 찾을 때까지 계산·시험·실행) → 결함(방법을 못 찾으면 자신을 마지막 수단으로 사용) → 공포(내가 할 수 있었는데 하지 않은 결과로 누군가 죽는 것) → 갈등(각성자의 시대가 인간의 기술을 무의미하게 만들 수 있다는 사실) → 성장(모든 사람을 자신이 직접 구할 필요는 없다는 사실을 받아들임) → **최종 도달 인간상**: "내가 앞에서 다 해내는 사람"에서 "다른 사람들이 해낼 수 있도록 만드는 사람"으로 변화.

### 문태석을 대표하는 대사 (전체)

- "괴물이라고 별거 없어. 죽는 구조로 만들어져 있으면 죽어."
- "안 죽는 게 아니라, 아직 우리가 방법을 못 찾은 거야."
- "공학자가 왜 군대에 왔냐고? 사람이 살아야 연구도 하지."
- "계산 끝났어. 이제 쏴."
- "내가 들어갈게. 너희는 여기서 쏴."
- "야, 박사 학위가 괜히 박사 학위인 줄 알아? 내가 죽을 자리인지 아닌지는 내가 제일 잘 알아."
- "문제는 괴물이 아니라 시간이야."
- "사람이 괴물보다 약한 건 맞아. 그래서 도구를 만드는 거야."
- "우리가 신이 아니라는 건 알아. 그래서 포를 쏘는 거야."

### 박사라는 사실이 알려진 이후

처음엔 병사들이 "박사까지 따서 왜 군대에서 포탄을 쏘냐"며 이상하게 여겼으나, 문태석은 "논문보다 이게 사람을 더 많이 살릴 때도 있더라"고 대수롭지 않게 답한다. 학위를 자랑하지 않고 오히려 부대원들에게 장비 원리를 설명해 준다 — 정답을 외우게 하지 않고 왜 그런지 이해하게 만드는 교육 방식 덕에, 그의 부대원들은 장비가 고장 나도 임기응변으로 해결하는 능력이 뛰어나다.
