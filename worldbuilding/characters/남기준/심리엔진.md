## 4. BASELINE SHIFT ENGINE

### TRIGGER_EVENT_A — "아이를 구한 몬스터" 사건 (2023년)

```
TRIGGER: 몬스터가 인간 아이를 구하는 장면을 직접 목격 + 아이가 "왜 죽여요?"라고 직접 질문
IMMEDIATE_RESPONSE: Persona_Durability 80→15 (-65, 일시 붕괴 직전) → 방아쇠를 당김으로써 즉시 자기방어적으로 회복
PSYCHOLOGICAL_SHIFT:
  - Humanity_Scan: 35% → 45% (+10, 경계를 지키려는 강박이 더 강해짐)
  - Empathy_Scan: 25% → 15% (-10, ⚠경고 신호 — 인간에 대한 공감마저 좁아지기 시작)
  - Threat_Scan: 25% → 20% (-5)
  - Hierarchy_Scan: 5% → 5% (변동 없음)
  - Material_Scan: 10% → 15% (+5, 사건을 "처리 절차"로 재정의하려는 방어적 몰입)
CHECK: 45+15+20+5+15 = 100% ✅
결과: 반증을 마주하고도 이분법을 포기하지 않고 오히려 **경직**시킨다. 이 사건 이후 그는 이전보다 말이 적어지고, 기도 시간이 늘어난다.
```

### TRIGGER_EVENT_B — 인간에게로 번지는 잣대 (미확정 사건, 위 A 이후의 상태에서 파생)

```
TRIGGER: (미정 — 향후 지시로 구체 사건 확정 예정) 극악한 인간 범죄자·배신자를 마주하고 "이 자는 인간이 아니다"라고 스스로 판단하는 순간
IMMEDIATE_RESPONSE: Psychological_Safety 급락 후 "판단 기준=자기 자신"이라는 논리로 재봉합
PSYCHOLOGICAL_SHIFT (TRIGGER_A 이후 상태 35%(Human)+45%... 기준 재계산, TRIGGER_A 이후 값에서 재분배):
  - Humanity_Scan: 45% → 50% (+5, 판별 대상이 몬스터를 넘어 인간까지 확장)
  - Empathy_Scan: 15% → 10% (-5, 인간 전반에 대한 공감이 아니라 "그가 인정한 인간"에게만 국한)
  - Threat_Scan: 20% → 20% (변동 없음)
  - Hierarchy_Scan: 5% → 5% (변동 없음)
  - Material_Scan: 15% → 15% (변동 없음)
CHECK: 50+10+20+5+15 = 100% ✅
Core_Belief 변화: "인간에게만 영혼과 존엄이 있다 — 그 나머지는 내가 판단한다." → "영혼이 없는 자는 인간의 모습을 하고 있어도 사람이 아니다."
```

> **설계 의도 — 08-템플릿 표준 패턴으로부터의 의도적 이탈**: 템플릿은 통상 TRIGGER_A(파멸적 트라우마)/TRIGGER_B(구원·안전기지)를 대비시켜 캐릭터에 회복 경로를 준다. 남기준은 사용자 설계상 **A와 B 모두 그를 더 어둡게 만든다** — 두 트리거 사이에 구원이 없다. 이는 사용자가 명시한 "인간 VS 인간이 아니다의 판단이 자기가 되어버리는" 결말을 향한 의도적 편도(片道) 설계이며, 향후 그를 구원할 별도의 TRIGGER_C(백 정·문태석 등에 의한 개입)가 추가될 여지는 남겨둔다.

## 5. AFFORDANCE & NETWORK INTERACTION SCRIPT

### 5.1 관계별 스크립트

| 대상 | IF | THEN |
|---|---|---|
| 백 정 | 지능형 몬스터·모호한 존재를 살려두자고 제안하면 | 정중하지만 단호하게 반박, "제가 판단합니다"로 결론 — 백정은 이를 "신앙이 판결문이 됐다"고 인식 |
| 문태석 | 논리적 모순을 지적하면 | "논리의 문제가 아니라 신념의 문제"라며 논쟁을 신념 영역으로 이동, 악의 없이 태연함 |
| 오승우(생전) | 남기준의 확신을 걱정하는 발언을 하면 | 웃으며 가볍게 받아넘기지만, 오승우 사후 그 말("그 '사람'의 기준이 네 마음대로 바뀌면 어떡하려고?")이 계속 되새겨짐 — 유일하게 그의 확신에 남은 균열 |
| 민간인·아이 | 도움을 요청하거나 위협받으면 | 즉시, 전폭적으로 보호 — 이 반응만큼은 이분법과 무관하게 진심 |
| 지능형/경계선 개체 | 인간과 유사한 지능·언어·감정을 보이면 | Humanity_Scan 급상승 → 재해석 기제 가동("지능과 영혼은 다르다") → 처치 쪽으로 결론 |

### 5.2 실시간 트리거/방어기제

- IF 자신의 신앙적 확신이 논리적으로 반박당함 THEN "논리 vs 신념" 프레임 전환으로 논쟁 자체를 무력화한다.
- IF Persona_Durability가 임계값(10) 이하로 떨어짐 THEN 즉각적 행동(방아쇠, 임무 수행)으로 상황을 "종료"시켜 사고를 멈춘다 — 성찰을 회피하는 행동화(acting-out) 패턴.
- IF 혼자 있는 시간이 길어짐 THEN 기도 횟수가 늘어나며 "저는 사람을 죽이지 않습니다"를 반복 — 타인이 아니라 자기 자신을 설득하는 혼잣말.

## 6. ACTION STRATEGY FOR WRITER

**DO**
- 그를 처음 등장시킬 때는 반드시 "따뜻하고 헌신적인 인물"로 먼저 각인시킨 뒤, 이분법의 균열을 서서히 드러낼 것.

## 부록 — 사용자 제공 원본 전문

> 아래는 사용자가 제공한 남기준 캐릭터 설계 원문을 그대로 보존한 것이다(프로필.md에 이미 구조화되어 있으나, 스크립트 대사와 세부 논리 전개의 원형을 손실 없이 남기기 위해 재수록).

**도입 지시**: "남기준 자료 줄게. 그 방향이 훨씬 입체적입니다. 남기준을 '독실한 신자이지만 교리의 일부를 자기 입맛대로 왜곡한 인물'로 만들면 됩니다. 핵심은 단순한 광신도가 아니라, 본인은 진심으로 선을 행한다고 믿는데 외부에서 보면 위험한 빌런이라는 점입니다. 다만 실제 천주교 교리와는 분리해서, 남기준 개인이 만들어낸 사적인 신학으로 설정하는 게 좋습니다."

1. **핵심 컨셉**: 세계를 인간/인간이 아닌 것으로 나누는 이분법. 인간에게는 존엄·연민·구원 가능성이 있으나, 몬스터는 생명체이되 인간과 동등한 가치를 갖지 않는다.
2. **신앙의 형성**: 초기엔 살생을 괴로워함 → 신부에게 질문 → 침묵을 자의적으로 해석 → 확증편향 심화.
3. **논리적 함정**: "인간이 아니므로 죽여도 된다" → "인간인지 어떻게 아는가" → "인간은 인간이니까 압니다"의 자기완결적 순환.
4. **가장 무서운 부분**: 죄책감의 부재. 살생 후에도 기도할 수 있고, 오히려 "도구로 쓰인 것"에 감사한다.
5. **논리의 확장(위험 단계)**: 몬스터는 죽여도 된다 → 안 죽이면 인간을 위험에 빠뜨린다 → 죽일 수 있는데 안 죽이는 자는 배신자다.
6. **지능형 몬스터 사건(2022)** 스크립트: "죽이십시오." / "왜요?" / "몬스터니까요." / "지능이 있습니다." / "사람입니까?" / (대답 못함) / "그럼 됐습니다."
7. **아이를 구한 몬스터(2023)** 스크립트: 아이 "아저씨, 저 괴물이 저를 구해줬어요." → 남기준 "알고 있습니다." → 아이 "그럼 왜 죽여요?" → 대답하지 못하고 결국 방아쇠를 당김.
8. **대상별 태도 표**: 민간인(극도로 보호적), 동료(헌신적), 범죄자·인간(회개 가능성 인정), 적군 인간(죄책감을 느끼며 필요시 살생), 지능형 몬스터(극도의 경계), 일반 몬스터(죄책감 없음), 혼종(판단 혼란), 인간으로 변장한 몬스터(극도의 적대), 인간을 구한 몬스터(인정하기 어려움).
9. **백 정과의 충돌**: "저건 사람 아닙니다." / "사람처럼 생각하고 말하는데요." / "사람처럼 생각하는 것과 사람이 되는 건 다릅니다." / "그럼 뭘 기준으로 판단합니까?" / (침묵) / "제가 판단합니다."
10. **문태석과의 충돌**: "그건 논리적으로 말이 안 되는데요." / "논리의 문제가 아닙니다." / "그럼 뭡니까?" / "신념의 문제입니다." / "신념으로 생물을 죽여도 됩니까?" / "인간이라면 안 됩니다." / "몬스터라면?" / "죽여야죠."
11. **오승우와의 대화**: "기준아, 네가 그렇게 확신하는 게 제일 무서운 거야." / "무슨 말입니까?" / "사람 죽이는 놈들은 대부분 자기들이 옳다고 생각하더라." / (웃으며) "그래도 저는 사람은 안 죽입니다." / "그 '사람'의 기준이 네 마음대로 바뀌면 어떡하려고?"
12. **진짜 약점**: 자신의 신앙을 완전히 믿지 못해서 더 강하게 믿으려 함. "몬스터에게도 영혼이 있다면?"을 인정하는 순간 모든 살생을 재평가해야 하기에 더 강하게 부정한다. "저는 사람을 죽이지 않습니다"는 자기 자신을 설득하는 말이다.
13. **최종 지시(향후 확장 방향)**: "이후에 '사람이 아니다'가 다른 범죄자나 다른 사람들한테까지 전파해둘 수 있는 계기가 됨. 사람 VS 사람이 아니다의 판단이 자기가 되어버리는 경우가 생겨버림." — 이 문장이 위 섹션 4의 TRIGGER_EVENT_B 설계 근거다.
14. **최종 포지셔닝**: 완전한 악인이 아니다. 민간인·동료에게는 진심으로 헌신적이고 따뜻하나, 인간/비인간을 가르는 기준이 오직 자기 자신이라는 사실이 그를 서서히 위험하게 만든다.
