# 🧠 인물 심리 엔진 템플릿

> 요르문간드 연대기의 주요 인물(특히 정계·재계·비밀조직 실세급 캐릭터)을 만들 때 쓰는 심리 프로필 골격입니다. 여기서 완성한 프로필은 실제 스토리 집필의 "내부 연산 참고자료"이며, 독자에게 노출되는 정식 등재는 [04-인물사전.md](./04-인물사전.md) 형식(소속/국적/능력/개요/의의)으로 별도 정리합니다. 즉 이 문서 = 캐릭터를 일관되게 움직이기 위한 설계도, 04-인물사전.md = 세계관 위키에 실리는 완성된 프로필.

## 사용 방법
1. 1~6번 섹션을 순서대로 채워 캐릭터의 정적 설계도(캐릭터 바이블)를 완성한다.
2. 완성 후 "검증 체크리스트"로 수치 예산·논리 모순을 확인한다.
3. 실제 집필 중 4번의 트리거 이벤트가 발동하면 "7. 트리거 발동 로그"에 연도·경위·전이 결과를 기록해 그 인물의 서사적 변화를 추적한다 (한 인물이 이야기 내내 어떻게 변해왔는지 나중에 참조하기 위함).
4. 캐릭터가 스토리에 정식 등장하면 `worldbuilding/characters/<인물명>/` 폴더를 만들어 요약 프로필을 `프로필.md`로, 이 문서 형식 그대로 작성한 전체 프로필을 `심리엔진.md`로 나누어 저장하고, 04-인물사전.md 색인에 링크를 추가한다.

## 1. NARRATIVE & EXPLICIT PERSONALITY (서사 및 명시적 성격 프로필)
평소 평온한 상태(배터리 안정 상태)에서 유지되는 캐릭터의 뼈대·성격 유형·사회적 가면.

- **AGENT_ID**: 식별용 코드나 가명 (정식 이름은 미확정 상태로 둬도 됨) / 국적 / 나이
- **기본 인적 사항**: 성별, 사회적 지위·직함(공식/비공식), 가족관계
- **인생의 핵심 트라우마**: 이 인물의 세계관을 형성한 결정적 사건 1개 — 막연한 "힘든 과거"가 아니라 구체적 사건과 그로 인해 굳어진 신념 문장으로 서술
- **사회적 페르소나**: 타인에게 주는 첫인상, 평소 유지하는 가면
- **에너지 효율성**: 내향/외향, 활동 시간대(아침형/저녁형) — 어떤 상황에서 행동 가중치가 붙는지

**EXPLICIT_TYPOLOGY (명시적 성격 유형 데이터)**
- **MBTI**: 4자리 + 한 줄 해석
- **에니어그램**: 번호 + 유형명 + 핵심 동기 한 줄
- **Big 5 성격 특성 점수 (0~100, 서로 독립적 — 합산 제약 없음)**
  - 외향성(E):
  - 신경증(N):
  - 성실성(C):
  - 우호성(A):
  - 개방성(O):

## 2. INTERNAL COGNITIVE PARAMETERS (내부 인지 및 왜곡 가중치)
외부 정보(타인의 제안, 대사, 돌발 변수)가 들어왔을 때 이 인물이 실시간으로 연산하는 인지 레이더.

**ATTENTION_WEIGHT (정보 감지 센서 레이더, 총합 반드시 100%)**
- `Hierarchy_Scan` (권력/서열/무시 감지): __%
- `Threat_Scan` (위험/통제상실 감지): __%
- `Material_Scan` (실리/자원 감지): __%
- `Empathy_Scan` (감정/공감 감지): __%
- *(필요시 항목 추가/삭제 가능 — 단, 항상 합계 100%를 유지할 것. 아래 "검증 체크리스트" 참조)*

**COGNITIVE_BIAS_LOGIC (고착된 인지 오류)**
- 이 인물이 상시 걸려 있는 인지 왜곡 패턴 (이분법적 사고, 파국화, 과잉일반화 등) — TRUE/FALSE 플래그 + 발동 조건
- **Core_Belief**: 인물의 행동 논리를 한 문장으로 압축한 핵심 신념

## 3. REAL-TIME PSYCHO-SOMATIC BATTERY (실시간 스태미나 수치)
스토리 진행 중 변수와 부딪히며 깎이는 내면 배터리. 이 수치가 임계값 아래로 떨어지면 1번의 명시적 성격이 붕괴되고 방어기제가 노출된다.

```json
{
  "METRICS": {
    "Physical_Energy": 100,
    "Dopamine_Battery": 100,
    "Psychological_Safety": 100,
    "Persona_Durability": 100
  }
}
```

각 수치마다 다음 세 가지를 반드시 명시한다 (원본 템플릿에는 소모 조건만 있고 회복 조건이 없어 배터리가 한 방향으로만 깎이는 구조적 결함이 있었음 — 아래처럼 양쪽을 다 정의할 것):
- **소모 조건**: 어떤 사건·상호작용이 이 수치를 깎는가
- **회복 조건 (충전원)**: 어떤 사건·환경이 이 수치를 채우는가 — 예: 신뢰하는 인물과의 독대, 권력 재확인, 물리적 휴식 등
- **임계값별 결과**: 예) 30 이하 → 이성 판단 스크립트 정지 / 0 도달 → 방어기제 완전 노출

| 수치 | 소모 조건 | 회복 조건 | 임계값 |
|---|---|---|---|
| Physical_Energy | | | |
| Dopamine_Battery | | | |
| Psychological_Safety | | | |
| Persona_Durability | | | |

## 4. BASELINE SHIFT ENGINE (인생 경험에 따른 성격·기본치 영구 전이 규칙)
특정 임계값 이상의 강렬한 경험을 겪을 때 1·2번 수치가 영구적으로 리매핑되는 규칙. 통상 "파멸 트리거(A)"와 "구원 트리거(B)" 한 쌍으로 설계해 인물이 양방향으로 변할 수 있게 한다.

```markdown
- [TRIGGER_EVENT_A: 파멸적 트라우마 / 통제력 상실]
  - 조건:
  - 성격 및 수치 전이:
    - MBTI 변형:
    - Big5 변동폭:
    - ATTENTION_WEIGHT 재분배 (⚠️ 합계 100% 유지 필수 — 한 항목을 올리면 반드시 다른 항목에서 같은 폭만큼 뺄 것):
    - Core_Belief 변경:

- [TRIGGER_EVENT_B: 구원 / 안전기지(Anchor) 확보]
  - 조건:
  - 성격 및 수치 전이:
    - MBTI 변형:
    - Big5 변동폭:
    - ATTENTION_WEIGHT 재분배 (합계 100% 유지):
    - COGNITIVE_BIAS_LOGIC 플래그 변경:
    - Persona_Durability 소모율 변화:
```

**설계 원칙**
- 트리거는 "인생을 뒤흔들 만큼 드문 사건"이어야 한다 — 매 장면마다 발동하면 배터리 시스템 자체가 무의미해진다.
- 한 인물에게 A/B 트리거를 각 1~2개씩만 설계하고, 실제 발동 여부는 스토리 전개에 맡긴다 (미리 다 써버리지 말 것).
- ATTENTION_WEIGHT 재분배 시 반드시 합계 100%를 검산할 것 (아래 검증 체크리스트 참조).

## 5. AFFORDANCE & NETWORK INTERACTION SCRIPT (주변 인물·상황 조건문)

### 5.1 주변 인물(Network) 대응 규칙
관계 대상별로 이 인물이 어떤 자아 상태(방어형/이성형/통제형 등)로 전환되는지 정의.

- **[관계 대상 이름/유형]**
  - `IF` 대화 상대가 이 인물일 때
  - `THEN` 발동하는 자아 상태와 그 이유
  - *(부가 조건: 이 관계 안에서도 상시 백그라운드로 감시하는 레이더가 있다면 명시 — 예: 신뢰하는 상대라도 배신 징후는 계속 스캔)*

### 5.2 실시간 트리거 및 방어기제 발동 규칙
- **[RULE: 조건 이름]**
  - `IF` 어떤 상황 노출 시
  - `THEN` 어떤 배터리가 얼마나 깎이는가
  - `IF` (배터리 > 임계값) → 1차 징후 (경미한 행동 변화)
  - `ELSE` (배터리 <= 임계값) → 명시적 성격 제어권 상실, 숨겨진 방어기제 폭주 — 구체적 대사/행동 패턴 예시

## 6. ACTION STRATEGY FOR WRITER (집필 시 대처 가이드)
이 인물을 상대하는 다른 캐릭터(또는 독자가 감정이입할 시점인물)가 이 인물로부터 원하는 반응을 끌어내거나 충돌을 피하려면 어떻게 해야 하는지.

- **Do**: 이 인물이 실제로 반응하는 설득 방식(힘·실리·서열 등 구체적으로)
- **Don't**: 이 인물에게 절대 통하지 않고 오히려 역효과를 부르는 접근 방식과, 그 시도가 감지됐을 때 내부적으로 상대를 어떻게 재분류하는지

## 7. 트리거 발동 로그 (장기 기억 저장소)
스토리 진행 중 4번 섹션의 TRIGGER_EVENT가 실제로 발동할 때마다 아래에 한 줄씩 누적 기록한다. 이 인물이 이야기 내내 어떻게 변해왔는지 나중에 참조하기 위한 "장기 기억"이며, 캐릭터 바이블(1~6번)이 정적 설계도라면 이 로그는 그 설계도가 실제로 어떻게 소진·갱신되어 왔는지 보여주는 이력이다.

| 연도/시점 | 발동 트리거 | 경위(무슨 일이 있었나) | 전이 결과(무엇이 바뀌었나) |
|---|---|---|---|
| | | | |

- 같은 트리거가 두 번 이상 발동했다면 그때마다 강도가 달라졌는지(둔감화/민감화) 함께 적어둘 것.
- 이 로그가 쌓이면 04-인물사전.md 등재 시 "성격 변화 서사"를 요약해 넣을 수 있다.

## 검증 체크리스트 (템플릿 완성 후 반드시 확인)
- [ ] ATTENTION_WEIGHT 4~5개 항목 합계가 정확히 100%인가?
- [ ] TRIGGER_EVENT A/B 각각의 재분배 후에도 ATTENTION_WEIGHT 합계가 100%를 유지하는가? (원본 초안에서 이 부분이 어긋났던 적이 있음 — 예: 50%→40%(-10)인데 다른 항목은 30%→50%(+20)로 조정해 합계가 110%가 되는 식의 오류. 한쪽을 올린 폭만큼 반드시 다른 쪽에서 빼야 한다.)
- [ ] 4개 배터리 수치 모두 "소모 조건"과 "회복 조건"이 둘 다 정의되어 있는가? (회복 조건이 없으면 배터리가 한 방향으로만 깎여 스토리 후반부에 캐릭터가 항상 붕괴 상태로 고정되는 문제가 생긴다.)
- [ ] Core_Belief가 실제 대사로 옮겨 쓸 수 있을 만큼 구체적인 문장인가? ("힘이 세상을 지배한다" 같은 추상적 격언보다 "약해지는 순간 모든 걸 잃는다"처럼 이 인물만의 절박함이 묻어나는 문장이 좋다)
- [ ] 트라우마·트리거가 세계관 정전(예: 요르문간드 연대기의 연도별 캐논)과 시기적으로 모순되지 않는가?
- [ ] 이 인물이 마나/영능 또는 하드SF 능력 보유자라면 [06-하드SF-초인체계.md](./06-하드SF-초인체계.md) 또는 마나 체계 규칙과 배치되지 않는가? (순수 인간 정치·비즈니스 인물이라면 해당 없음)

## 예시 적용: S-3 (러시아, 61세) — 초안

> 사용자가 최초로 제시한 원안을 이 템플릿 구조에 맞춰 정리한 예시입니다. 실제 세계관에 정식 등재하려면 국적·소속 조직(예: 시베리안 아이언, 오버사이트류의 국가별 특무기관과의 연계 여부 등)을 결정해야 합니다.

**1. 서사**
- MBTI ISTJ / 에니어그램 8번(도전가) / Big5: E20 N75 C90 A15 O10
- 트라우마: 소련 붕괴를 직접 겪으며 형성된 "힘없는 국가는 죽는다"는 실존적 공포
- 페르소나: 과묵하고 위엄 있는 "강한 남자", 저녁형·내향형

**2. 인지 파라미터**
- Hierarchy_Scan 50% / Threat_Scan 30% / Material_Scan 15% / Empathy_Scan 5% (합 100% ✅)
- 이분법적 사고 TRUE, 파국화 TRUE
- Core_Belief: "힘의 논리가 세상을 지배하며, 약해지는 것은 곧 죽음이자 파멸이다."

**3. 배터리** — Physical_Energy 100 / Dopamine_Battery 100 / Psychological_Safety 100 / Persona_Durability 100
- 회복 조건 보완 예시: Psychological_Safety는 전우 E와의 독대, 완전히 통제된 자기 공간 점유로 충전(원안 그대로 유지). Physical_Energy는 나이 특성상 회복이 느리다는 제약을 명시 — 예: 완전한 하루 휴식 없이는 30 이상 회복 불가.

**4. 베이스라인 시프트 (수정본 — 퍼센트 예산 오류 수정)**
- TRIGGER_A(배신·숙청 위기): Hierarchy_Scan 50%→25%(-25), Threat_Scan 30%→50%(+20), Material_Scan 15%→20%(+5), Empathy_Scan 5%→5%(±0) → 합계 100% ✅ (원안은 Hierarchy 50→40, Threat 30→50만 조정해 합계 110%가 되는 오류가 있었음 — Material_Scan을 5%p 올려 보정)
- TRIGGER_B(구원): 원안 그대로(N -30%, A +20%, 이분법적 사고 FALSE 전환, Persona_Durability 소모율 -50%) — Big5는 독립 척도라 합산 제약이 없어 문제 없음.

**5. 관계 스크립트**
- 전우 E: 방어벽 예외, 이성 자아 가동
- 측근 F: 통제적 자아 가동 + Hierarchy_Scan 백그라운드로 배신 징후 상시 감시

**6. 집필 가이드**
- Do: 군사력·지위·자원 등 눈에 보이는 실리를 건조하게 제시, 1:1 기브앤테이크로 접근
- Don't: 정의·평화·인도주의 같은 이상론 — 시도 즉시 "가치 없는 약자" 또는 "위협 분자"로 재분류되어 소통 단절
